EIRON JAMES M. MACATANGAY - PERSONAL PORTFOLIO
================================================

FILES INCLUDED
--------------
1. index.html
   The main webpage. It contains the page structure and the JavaScript
   interactions (mobile navigation, active section highlighting, scroll
   reveals, and certificate preview modal).

2. style.css
   The visual design, colors, layout, responsive styles, and animations.

3. index_html_code.txt
   An exact plain-text copy of index.html.

4. README.txt
   This instruction file.

HOW TO OPEN THE WEBSITE
-----------------------
1. Extract the ZIP file into a folder.
2. Keep index.html and style.css together in the same folder.
3. Double-click index.html, or right-click it and choose a browser.
4. For the best experience, use an updated version of Chrome, Edge, Firefox,
   or another modern browser.
5. An internet connection is only needed for the optional Google Fonts.
   The website itself does not require a framework or build process.

PERSONALIZE YOUR CERTIFICATES
-----------------------------
The certificate cards currently use clearly marked visual placeholders.
They are not images of your real certificates.

To add an actual certificate image:
1. Put the image file in the same folder as index.html (or create an images
   folder and place it there).
2. Open index.html in a text editor.
3. Find the relevant certificate button and its data-image="" attribute.
4. Put the image path inside the quotation marks. Example:
   data-image="images/basic-c-certificate.jpg"
5. Save the file and refresh the browser.

You can also update the data-detail text with accurate certificate details.
Do not label a placeholder as an actual certificate.

GITHUB PAGES PUBLISHING GUIDE
-----------------------------
1. Create or sign in to your account at https://github.com/.
2. Click the + button near the top-right, then choose "New repository".
3. Enter a repository name, such as "ej-personal-portfolio".
4. Choose Public (recommended for a free GitHub Pages site), then create
   the repository.
5. On the repository page, choose "Add file" > "Upload files".
6. Upload index.html, style.css, and any certificate image files you added.
   You may also upload README.txt and index_html_code.txt.
7. Scroll down and click "Commit changes".
8. Open the repository's Settings tab.
9. In the left menu, select "Pages".
10. Under "Build and deployment", choose "Deploy from a branch".
11. Select the "main" branch and the "/ (root)" folder, then click Save.
12. Wait for GitHub Pages to finish publishing. Refresh the Pages settings
    page if needed.
13. GitHub will show the published website address in the Pages section.
    Use that exact address; it usually follows this pattern:
    https://YOUR-USERNAME.github.io/REPOSITORY-NAME/
14. Open the address on a phone and a computer to test the layout, links,
    certificate preview cards, and navigation.
